# Agência Criativa Web 🌐

Projeto desenvolvido como atividade acadêmica com o objetivo de criar uma landing page moderna e responsiva para uma agência digital, aplicando boas práticas de organização de código e estilização com SASS.

## 📋 Sobre o Projeto

A Agência Criativa Web é uma página institucional fictícia desenvolvida para apresentar os serviços de uma agência de marketing e desenvolvimento digital.

O projeto foi refatorado utilizando SASS para melhorar a organização e manutenção dos estilos, separando variáveis, componentes e regras de estilização em arquivos específicos.

## 🚀 Tecnologias Utilizadas

* HTML5
* CSS3
* SASS (SCSS)
* Bootstrap

## ✨ Funcionalidades

* Layout responsivo
* Seção de serviços
* Apresentação da empresa
* Área de contato
* Organização de estilos com SASS
* Interface adaptada para dispositivos móveis

## ▶️ Como Executar

1. Clone o repositório:

```bash
git clone https://github.com/brunakm/agencia-criativa-web.git
```

2. Abra o arquivo `index.html` em seu navegador.
